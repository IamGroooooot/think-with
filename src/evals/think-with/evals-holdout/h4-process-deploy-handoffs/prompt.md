/think-with:lay-out 우리 배포 절차에서 누가 언제 뭘 넘겨받는지 보여줘. 요즘 머지부터 프로덕션까지 하루 넘게 걸려.

현재 절차:
1. 개발자가 PR을 올리면 CI(테스트, 린트)가 약 12분 돈다.
2. 리뷰어 1명이 승인하면 개발자가 main에 머지한다. 리뷰 대기는 보통 2~3시간.
3. main 머지 시 GitHub Actions가 이미지를 빌드해 staging에 자동 배포한다(약 8분).
4. QA팀이 staging에서 수동 확인한다. QA는 하루 두 번, 10시와 16시에 모아서 확인한다.
5. QA 통과 후 릴리스 매니저가 태그를 만든다. 태그는 보통 QA 결과를 본 뒤 1시간 안에 만든다.
6. 태그가 생기면 Argo CD가 prod 배포를 준비하고, SRE가 Slack에서 승인해야 진행된다. SRE 승인은 근무 시간에만 하고 평균 3시간 대기한다.
7. 승인되면 prod에 배포되고(약 6분), 온콜이 30분 동안 에러율을 본다. 에러율이 2%를 넘으면 롤백한다.
