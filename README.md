# Think with plugin
> Things to think with

## Skills

- [lay-out](src/skills/lay-out/README.md): 필요한 관계만 골라 작고 읽기 쉬운 시각 자료로 설명합니다.
- [get-advice](src/skills/get-advice/README.md): 관련 연구와 전문가 자문을 찾고, 답변의 근거를 독립적으로 검증합니다.

## How to install

### Claude Code

```bash
claude plugin marketplace add IamGroooooot/think-with
claude plugin install think-with@think-with
```

### Codex

```bash
codex plugin marketplace add IamGroooooot/think-with
codex plugin add think-with@think-with
```
