# Final factual verification

Check the actual draft, including field descriptions, evidence-density claims,
expert findings, learning resources, and any proposed causal or transfer claims.
Simple direct answers use the same final pass, sized to their material claims;
omit empty bundles rather than inventing research work.

Give each checker a disjoint bundle with claim IDs, exact draft passages, cited
URLs, and the original user request and relevant later corrections verbatim.
Use shared files when available; a claim list or context summary is navigation,
not a replacement for those texts. Include the observed tool results relevant to
claims about completed work, identifying summaries as summaries. If a record is
unavailable, state that limit instead of reconstructing it from the draft.

Do not provide the author's confidence, other checkers' verdicts, or an instruction
to approve. Independent bundles can run concurrently. Keep a shared citation with
its dependent claims in the same bundle. Track coverage so no material claim
disappears between passes.

```text
Fact-check these draft claims. You are checking evidence, not defending the draft.
Use the assigned evidence and public sources. Read assigned execution records
only for process claims; prior agent conclusions are not independent verification.
Do not read local skills, memory, evals, or unrelated agents' work.
Do not delegate. Original user context: [verbatim text or readable file].
Claim bundle: [IDs, exact draft text or readable file, URLs].
Execution evidence: [relevant observed tool results; unavailable records marked].

For each claim check:
- Does the cited paper/source exist, with matching title, authors, and date?
- Does the opened source support the stated result, population, and magnitude?
- Are correlation, causation, certainty, consensus, and evidence quality overstated?
- Does applying this result to the user's situation require an unproved leap?

Separate published findings, user-provided facts, and labeled hypotheses. Check
user facts for fidelity to the supplied context, not against public papers.
A labeled inference does not need a study testing that exact example: check
whether the reasoning fits the evidence, overlooks alternatives, or implies
certainty it has not earned. Verify process claims against available execution
records; unavailable records are a verification limit, not evidence of fabrication.

Return all IDs as supported / needs correction / unsupported / unverifiable.
Group supported IDs by source and shared limits; detail other verdicts and
corrections individually. List unassessed IDs explicitly.
Distinguish a search failure or inaccessible full text from a fabricated source.
An abstract may verify bibliographic details without verifying a specific result.
Do not add new uncited factual claims in the correction.
```

Resolve factual disagreements against the sources, not by majority vote. Preserve
legitimate uncertainty. A proposed small test need not already have a proven
outcome, but must not be phrased as if it does. A new substantive factual claim
introduced during correction also needs checking.

Experts and checkers return to the consultation coordinator; a delegated
coordinator completes the final pass itself. If the checker model is unavailable,
disclose a model substitution or check in-session with the independence limit.
