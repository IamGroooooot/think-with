# Swimlane

Use lanes to show responsibility and handoffs, not message timing. Repeat the owner when side-by-side lanes would wrap.

```text
[Customer]  Submit order
     |
     v
[App]       Validate cart
     |
     v
[Payment]   Authorize payment
     |
     v
[App]       Create order
     |
     v
[Customer]  See confirmation
```
